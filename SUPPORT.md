# Support

## Questions and usage help

Search existing issues and discussions first. For reproducible bugs, open a bug
report using the [bug report template](.github/ISSUE_TEMPLATE/bug_report.md).
For ideas and improvements, use the [feature request template](.github/ISSUE_TEMPLATE/feature_request.md).

When asking for help, include the relevant Node.js and npm versions, the command
you ran, the expected behavior, and the actual output. Remove credentials and
personal data before posting.

## Security issues

Do not use public issues for security vulnerabilities. Follow the process in
[SECURITY.md](SECURITY.md).

## Contact

For project-specific questions that cannot be handled in an issue, contact the
repository maintainers through GitHub.
